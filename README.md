# GAD OPERASIONAL
Aplikasi Android laporan operasional kendaraan/event.

Fitur:
- Tanggal, jenis event, lokasi, kendaraan, nomor polisi, nama driver.
- Uang operasional diterima.
- Solar/Bensin, Tol, Parkir, Security/Ormas, Makan Crew.
- Hitung total pengeluaran dan sisa otomatis.
- Riwayat laporan tersimpan di perangkat (localStorage).
- Cetak laporan melalui dialog print Android.
- Bagikan teks laporan dan WhatsApp.

Build: buka folder ini di Android Studio, tunggu Gradle Sync, lalu Build > Build APK(s).
